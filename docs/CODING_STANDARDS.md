# Estándares de Código

Nunca duplicar componentes.

Antes de crear un componente nuevo revisar si ya existe uno reutilizable.

Mantener el diseño existente.

No modificar componentes visuales sin autorización.

Todos los componentes deberán estar tipados.

Usar TypeScript.

No acceder directamente a Firestore desde componentes visuales.

Toda comunicación deberá hacerse mediante Services.

No mezclar lógica con UI.

Mantener separación entre:

components

hooks

services

contexts

utils

features

Antes de modificar archivos:

Explicar qué archivos serán modificados.

Justificar cada cambio.

No eliminar funcionalidades existentes.
